2. Qué datos tratamos y para qué

Esta web ofrece enlaces para contactar por correo electrónico y teléfono. Si nos escribes, trataremos los datos que incluyas en tu mensaje, como tu nombre, dirección de correo y detalles de tu proyecto, para responder a tu consulta y gestionar la relación que pueda surgir.

3. Base jurídica y conservación

La base para responder a una consulta es la solicitud que nos haces antes de una posible contratación o, cuando corresponda, el interés legítimo en atenderla. Si se inicia una relación profesional, los datos necesarios se tratarán para gestionarla y cumplir las obligaciones legales aplicables.

Las consultas se conservarán durante el tiempo necesario para responderlas y atender las responsabilidades que puedan derivarse. Los datos vinculados a contratos y facturación se conservarán durante los plazos exigidos por la normativa aplicable.

4. Destinatarios y servicios externos

Para gestionar la web y el correo pueden intervenir proveedores que prestan estos servicios. Esta web carga tipografías de Google Fonts y contiene enlaces a sitios externos, como proyectos, Instagram y LinkedIn. Al abrir un sitio externo, su responsable aplica su propia política.

5. Tus derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad de tus datos, cuando corresponda, escribiendo a michaelromevi@gmail.com. También puedes reclamar ante la Agencia Española de Protección de Datos.

6. Actualizaciones

Esta política se actualizará si cambian los servicios o el tratamiento de datos de la web. Fecha de última revisión: 11 de noviembre de 2026.
